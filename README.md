# Airfoil Design Using SolidWorks

## Overview

This project focuses on the design and 3D modeling of a NACA airfoil using SolidWorks. The objective was to create an accurate aerodynamic profile and develop a wing model suitable for aerospace and engineering applications. Airfoil coordinates were imported and converted into a precise sketch, which was then used to generate a three-dimensional model.

## Features

* NACA airfoil profile generation using coordinate data
* Accurate 2D sketch creation in SolidWorks
* 3D wing modeling through extrusion and lofting techniques
* Parametric design for easy modification of dimensions
* Engineering visualization of aerodynamic geometries

## Software Used

* SolidWorks 2023

## Methodology

1. Selected a suitable NACA airfoil profile.
2. Imported airfoil coordinate data into SolidWorks.
3. Generated the airfoil sketch and refined the geometry.
4. Created a 3D wing model using extrusion and loft features.
5. Evaluated the model for geometric accuracy and design suitability.
